# INDGE Services Website

New ground-up Next.js website for INDGE Services Ltd.

## Quick start

```bash
git clone https://github.com/Indgeservices/indge-services-website.git
cd indge-services-website
npm run setup
npm run dev
```

Open `http://localhost:3000`.

## Milestone 001

- Next.js + TypeScript + Tailwind foundation
- dark graphite / INDGE blue design system
- responsive shared header/footer
- first production homepage structure
- baseline metadata, robots and sitemap
- one-command local setup

The current live Squarespace site is not changed by this repository.

## Content safety

Design mockups created during planning contained generated placeholder claims, review text, dates and opening hours. Production content must be verified before launch.

## Photography

The first implementation intentionally reserves editorial image areas without baking generated website screenshots into the product. Final photography should use real INDGE vehicles, tools and people where possible.
